Low-voltage electrical design in one workspace.

LV Design Studio brings single-line diagrams, load schedules, equipment sizing, calculations, drawings and reports together in an offline desktop and browser application.

One project model

Design information is shared across calculations, drawings and deliverables, reducing repeated entry while keeping the engineer responsible for every design decision.

Network and schedules

Build board hierarchies, load schedules and single-line diagrams from the same project data.

Electrical calculations

Check cable and breaker sizing, voltage drop, short circuit, earthing, protection coordination, transformers, generators and power factor correction.

Drawings and deliverables

Prepare drawing sheets, schedules, bills of quantities and engineering reports from the current design model.

Independent cross-checks

Compare selected studies with optional OpenDSS and pandapower engines installed on your own computer.

Private by design

The browser version keeps projects in that browser profile. The desktop application stores projects as local JSON files that can be backed up or placed in a desktop-synchronised folder.

No account or hosted project database is required. Download project backups regularly because clearing browser data removes browser-stored projects.

Read the privacy guidance

Engineering responsibility

The calculations are first-pass design checks, not a substitute for an engineer's verified study. Built-in cable values are approximate references until replaced with manufacturer data, and some study methods are intentionally simplified.

The software does not represent an electrical authority. Review the documented assumptions, limits and required independent checks before using an output for final design.
