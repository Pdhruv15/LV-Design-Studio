Design CAD → Draw ribbon: fit without scrolling — mockup (2026-11-07)

Today the Draw sub-tab holds about 35 full-size buttons (File, Draw, Modify, Edit, Annotate, View): 2,446 px, so it scrolls sideways on every normal screen. Four ways to fit it — pick an option and a screen width; the meter shows whether the row fits. The tools themselves, their commands and their order do not change.

  • Recommended: E — engineers used to other CAD programs find every tool where they expect it: the same panel names and order (Draw, Modify, Annotation, Layers, Properties), the same 3 × 4 Modify grid, the same split buttons (Trim/Extend, Fillet/Chamfer, Array), the same large Line / Polyline / Circle / Arc, Text / Dimension. It stays one sub-tab, as CAD programs usually keep all of this on Home. Our own engineering tools (Rooms, Cables, Devices, Wiring) stay on the Plan sub-tab, as dedicated electrical CAD products keep theirs on their own tabs.
  • D was: It is the only one that fits a 13″ screen (1280 px) without scrolling, and the most used edit tools keep full-size buttons. Draw sub-tab: File, Draw, Annotate, View; Modify sub-tab: Select, Modify, Edit. The command line (TRIM, O, F…) and the toolbar beside a picked object stay as they are, so a tool on the other sub-tab is still one key or one click away.
  • On a window narrower than the row, the remaining full-size buttons shrink to small ones before anything scrolls (as Office ribbons do), so even a split screen stays usable.
  • Option A can also apply to the Plan sub-tab (Devices and Edit devices) and Sheets if they grow; today they fit at 1440.
  • Hover still shows each tool's full description with its command; small buttons keep their names, so nothing becomes icon-only.
