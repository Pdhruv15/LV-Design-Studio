6The Rules sheet — the authority's settings inside Sheets (read only)

Rules — DEWA (Dubai) v1 · from the project · read only. To change a value: Standards {>} Design references.
Using the rules in your own columns
FormulaGivesWhat it is
=MAXBREAKER(F8)20Largest breaker the table allows on the wire in F8 (4 mm²)
=MINWIRE(E8)10Smallest wire the table allows for the breaker in E8 (40 A)
=RULE("VD limit")4A design value of the project's authority set
=IF(E8<=MAXBREAKER(F8),"OK","CHECK")CHECKYour own pass / fail column
=VLOOKUP(F8,Rules!A13:B19,2,0)20A plain look-up into the Rules sheet
In a saved .xlsx the Rules sheet is written as plain values with the authority set's name, version and date. MAXBREAKER, MINWIRE and RULE keep their last values there.

Three levels
Built-in authority formRead only. Updated with the app.
Your office formIn your library, shared through Library.json. Builds on the built-in form.
This projectKept in the project file. Save to my formats to use it again.
One copy of the rulesRules, limits and format are copied into the project when it starts. The table, Sheets and the output all read that copy.
Table and sheetThe Load schedule tab stays the working table. Sheets shows the same circuits as the form. A change in a linked cell reaches the project only through Apply to project.
Limits are enforced onceThe sizing applies the tables (size up, warn or off). Sheets shows the result and marks a cell that breaks a limit.
Your own columnsA formula column or a free column can be added to a format. A free column is kept with each circuit.
ADDC and EtihadWETheir forms are not in the app. They start on the General form until the official forms are added, or you make the format from your own Excel file.
Not drawnThe Connected load and MD form, TCL summary and Busbar riser take formats the same way, in a later step.
