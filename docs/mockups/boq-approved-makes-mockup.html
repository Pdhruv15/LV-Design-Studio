BOQ — approved makes, specification references and preambles (mockup)

Item 3 of the BOQ plan. The office keeps one list of up to three approved makes per equipment category, each with a specification clause. A project starts from that list and can change it. Each BOQ section can carry a preamble. The Excel and PDF BOQ print all three.

NewEverything else is today's BOQ page, unchanged.

1 · BOQ page — one new button in the price list bar

The count shows how many categories used in this BOQ have at least one make. It opens the dialog below in place of the table, like Markup and BOQ document do today.

Where it lives

  • Office list: saved beside the saved price lists (same library, same “use on other projects” behaviour), as many named lists as the office needs.
  • Project copy: stored in the project's BOQ settings; editing it never changes the office list until “Save as office list”.
  • Per-line override: an optional “Approved makes / Spec ref.” pair in the existing Edit item dialog (one more row of fields, same layout).
  • Make names are typed by the office; the app ships no manufacturer names.
