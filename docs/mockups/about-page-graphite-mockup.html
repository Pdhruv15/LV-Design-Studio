What it does

One project model

Design information is shared across calculations, drawings and deliverables, reducing repeated entry while keeping the engineer responsible for every decision.

Network and schedules

Build board hierarchies, load schedules and single-line diagrams from the same project data.

Electrical calculations

Check cable and breaker sizing, voltage drop, short circuit, earthing, protection coordination, transformers, generators and power factor correction.

Drawings and deliverables

Prepare drawing sheets, schedules, bills of quantities and engineering reports from the current design model.

Independent cross-checks

Compare selected studies with optional OpenDSS and pandapower engines installed on your own computer.

See the workspace

Views of the built-in demonstration project: the same project model across the design stages, calculations, drawings and deliverables.

Private by design

The desktop application stores projects as local JSON files. The browser app keeps projects in that browser profile. No account, telemetry or hosted project database is required.

Back up project files regularly; clearing browser data removes browser-stored projects.

Engineering responsibility

The calculations are first-pass design checks, not a substitute for an engineer's verified study. Built-in cable values are approximate references until replaced with manufacturer data, and some study methods are intentionally simplified. Nothing in the app constitutes approval by an electrical authority.
