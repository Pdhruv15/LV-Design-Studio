Sheet furniture, legends and title block frames in Design CAD mockup · 2026-11-09

What the SLD, board, riser and earthing sheets print around the drawing (frame, legend, cable schedule, abbreviations, notes, revision table, title block), what is fixed today, and how it could be set per sheet set and drawn as real CAD blocks. Prints stay black and white. Purple dashed = new. Tags: built no approval needed changes the sheet · approval

4Notes box placed by the set (above the title block, in the column, or a free corner), text 2.5 mm, width in mm; or moved by hand on the sheet as a paper object.
5Revision table with a fixed row count (4 / 6 / 8) so every sheet in the set has the same band; the latest issues fill it from the top.
6Title block is a frame template: the standard 180 mm block, a grid template, or the company's DWG block with its attributes mapped to {Fields} (see 4). The same template prints to PDF and goes to DWG as a block with attributes.
7Minimum drawing text per set (2.0 / 2.5 / 3.5 mm): the Fit may not go below it; the sheet reports "too small" earlier and the user splits it. Legend and furniture never scale with the drawing.

Rules

  • Defaults keep today's sheets. A project that never opens this palette prints as before, except where the drawing register already warns.
  • Set first, sheet second. Each control has the set's value; a sheet can override it (shown in italics, with Reset), as Page setup does now for paper and scale.
  • One renderer. The PDF (HTML in mm), the DXF / DWG (sheetDxf.ts) and the screen preview read the same furniture settings, so what the Sheets page shows is what prints.
  • Risers and earthing move their legend, notes and schedule out of the drawing SVG into the sheet column, the same way the SLD already does, so their text keeps the ISO height whatever the riser's height.
  • Legend on its own sheet: a new sheet kind "Legend and notes" numbered first in the set (E-SLD-000), listing every symbol of the set, the abbreviations and the general notes; the other sheets then show "LEGEND: SEE {LegendSheet}" and only their cable schedule.
  • Issue check: a change of furniture settings does not change a sheet's fingerprint (it is presentation), except the legend-on-own-sheet switch, which does (text moves).

4Title block frame as a CAD block in LVCAD

Follows the 2026-11-02 title block proposal (D1–D5). The piece that integrates it with the built-in CAD: a frame template is a block with attributes that the acadrust engine reads from the company file, the app fills from the project, and writes back as a block. The Design CAD layout tab (v2.050) gets the frame as its paper border, in place of the drawn frame.

5Related outputs: riser, earthing riser, load schedule

DB riser · Boards by level built v2.014

Today the legend sits in a 62 mm column at about 2 mm, while the riser table and notes are drawn inside the riser SVG and shrink with a tall building. Proposed: one 92 mm column as on the SLD (legend, riser table, notes at 2.5 mm); the riser alone fills the drawing area; match-line flags unchanged. approval

Earthing riser and schematic

Earthing schematic: a fixed 15-row legend box (520 px) and 8 notes inside the drawing. Earthing riser: a 3-row legend, notes 1–7 and the floor earth bar schedule inside the drawing. Proposed: move them to the column; notes become the set's notes with {Parameters} so wording is edited in one place; the schedule stays beside the riser. approval

Load schedule on a drawing sheet

Today the DB load schedule prints as its own A4 landscape page (Documents, 10 mm margins, 9 px text) with no sheet frame or title block, and the board sheet collapses the final circuits into one “REFER DB LOAD SCHEDULE” box. Proposed: a sheet kind "Board sheet with schedule": the DB's SLD on the left, its schedule table (Form 3 columns) on the right, one title block, numbered in the set and issued with it. approval

SLD and board sheets · text held at ISO height calculation and renderer

The Fit stops at the set's minimum text height (default 2.5 mm, today's effective ≈ 1.8 mm when 2.0 is chosen); the readiness check names the sheet and the height it would need. Cable text already switches to reference numbers below 0.25 mm per px; the same rule drives the legend's wrap. A new sheet is made from the overflow with a match reference. Prints stay the same where sheets already fit.

Legend content no UI change

Legend rows keyed by what is drawn on this sheet only (today: the sheet's project slice, so a panel-only sheet may still list the transformer). Panel symbols, starters, FA interface, SPD and PMU keep their rows. Labels shortened to one line at 2.5 mm in a 92 mm column (≈ 48 characters); the long explanation goes to the abbreviations.

DXF / DWG legend and notes no UI change

The legend written as a table of lines and TEXT on E-LEGEND (today: SVG geometry converted), notes as MTEXT paragraphs on E-NOTES with the column width, so a CAD team can edit them; the frame's grid lines drawn once.

6Suggested order

  1. Legend and furniture at ISO height (sections 2.2, 2.3, 2.7 and the risers' column): one change in sldSheet.ts / sheetDxf.ts and the three riser drawings. Biggest visible gain; output changes, so one approval. approval
  2. Sheet furniture settings (section 3) with today's output as the defaults: zone references, revision rows, legend place and columns, notes place, minimum text height. approval
  3. Legend on its own sheet and the load schedule board sheet (section 5), as new sheet kinds in the set. approval
  4. Title block frame as a CAD block (section 4): engine reads block and attribute definitions, import and map, write back as a block; the layout tab uses it as its border. Decisions D1–D5 of the 2026-11-02 note stand. approval
  5. Legend as a CAD table object on layouts, placeable by hand, kept in step with the symbols used (after 4; needs text styles and the table entity in the engine).

Not in this proposal: colour on prints, 3D or elevations, a change of the SLD symbols themselves.
