Where the densities are set

Today
  • Per project: section 2, Area schedule. Lighting, Power and Cooling W/m² of every space row can be typed.
  • Your own values: the buttons "Save densities as my library" and "Save as my type". They are kept on this computer only, not as a table you can open, share or back up with the database.
  • Indoor or outdoor: only by adding a Custom space and typing its three values each time.
  • A/C: typed as a cooling load (thermal). The cooling system's factor turns it into electrical kW.
Proposed
  • The same cells per project, with a Location on each row.
  • Your standard as a table in the LV Database folder: one row per space and location, with a Reference for each value. Several named standards, one picked per project.
  • Rows changed from the standard are marked, with Reset.

Decisions for you

  1. Building type: one list (recommended), or keep the buttons. The list saves a row of buttons and also shows your own types and each type's VA/m² band.
  2. Indoor and outdoor: one row per space and location, each with its own values (recommended), or one row per space with an outdoor factor. Rows are what a design guide gives, and they are easier to check.
  3. Where your standard is kept: a table in the LV Database folder, open in Sheets (recommended), or on this computer only as today.
  4. How many standards: several named ones (company, client, authority), one picked per project (recommended), or a single library.
  5. A/C figure: a choice per standard between cooling load and electrical load (recommended), or cooling load only as today.
