Design CAD — cursor and pick box

Proposal mockup (not built). The cursor shows what the canvas is waiting for: a point, objects, or nothing. It reads over any line colour, its box is the area a click hits, and the object a click would pick is marked first.

4 · Close-up at 4×

Drawn on a 4 px grid, one square per screen pixel. The outline hides the line behind it for 3 px each side; the marker is 14 px across (7 px from the centre), 2 px stroke over a 4 px outline.

5 · Sizes you can set

Crosshair size: % of the view (1–100, default 100)

Pick box size: px (3–30, default 12), drawn at 3×; the dashed square is the click area, the same size

Both sizes stay the same on screen at any zoom. Today the pick box defaults to 9 px and changes only the drawing, not the click area.
