7For you to decide

  1. Ribbon place: a small "References" button in the File group (as shown), or in View next to Layer manager?
  2. Type: both Overlay and Attach (Attach matters only when a saved DWG is opened elsewhere), or Overlay only for now?
  3. Printing: references print in grey by default — yes? Structure on, other services off?
  4. Bind: only into Save DXF / DWG (the saved copy gets the lines on STR-GF$0$S-GRID layers), never into the project. OK?
  5. Clip: rectangle and picked outline, with "show outside" (invert) later. OK?
  6. Changed files: desktop app checks each reference when the window comes back to the front and shows "Changed — reload". Auto-reload instead?

Not in this: 3D, elevations, references of images or PDFs, editing a reference in place.
