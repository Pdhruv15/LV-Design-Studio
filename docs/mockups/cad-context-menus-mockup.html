Design CAD — right-click menus by context

Proposal mockup (not implemented). The canvas right-click opens a different menu depending on what is under the cursor or picked, and whether a command is running. Order in every menu: repeat/recent → context actions → clipboard → common edits → selection → view → Properties. Menus stay short; rarely used actions live in flyouts (▸).
