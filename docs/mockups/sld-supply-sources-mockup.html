SLD — supply sources, RMU and package substation (proposal mockup, 2026-11-11)

Black-and-white, IEC 60617 style. Each symbol has its top terminal (supply side) at the top and its load side at the bottom, so they stack on the SLD like the boards do today. Labels under a symbol are drawn from its parameters (shown in italics in the examples).

B. MV switchgear and substations

SymbolTagComponentParameters (editable)Used by the calculations for
RMURing main unit — first-class item (today only a name on the transformer)
  • Configuration: ring (R) and tee-off (T) ways, e.g. RRT, RRTT, RRRT, extensible
  • Rated voltage 12 / 24 / 36 kV, rated current 630 A
  • Short-time rating Ik kA for 1 s / 3 s
  • Insulation: SF6 / solid / air / eco gas
  • T-off protection: fuse-switch (fuse A) or VCB + self-powered relay (50/51, 50N/51N)
  • Earth switch, VPIS, fault passage indicator
  • Motorised / SCADA-ready (remote)
  • Owner: authority / consumer
 RMU Ik check against the grid fault level, HV fuse / relay versus transformer inrush and LV discrimination, transformers per RMU (existing planner), RMU earth pits (existing earthing)
TXDistribution transformer — stays on the main board (as today), with more data
  • kVA, HV/LV kV, Uk %, X/R, vector group (as today)
  • Type: oil (ONAN) / cast resin (AN / AF)
  • Tap changer, e.g. ±2 × 2.5 % off-load
  • No-load and load losses W (efficiency tier)
  • Neutral: solidly earthed / own pit
 As today, plus losses and tap position in voltage drop
PSSPackage (compact) substation — RMU + transformer + LV board in one enclosure; typical for villa communities
  • Rating kVA (e.g. 500 / 1000 / 1500), HV/LV kV, Uk %
  • RMU configuration (as RMU)
  • LV incomer ACB rating A
  • LV outgoing ways: number and rating (fuse / MCCB)
  • Enclosure: steel / GRP, IP, kiosk / walk-in
  • Owner: authority / consumer; existing / new
  • Plot / location
 One block for the whole chain: fault level, LV way loading, spare ways, villa allocations; one BOQ line (or none if authority-owned)
FPLLV feeder pillar — street pillar between the substation and the villa meter cabinets
  • Incoming: cable from the PSS way, length m
  • Busbar rating A
  • Outgoing ways: count, fuse rating A (gG / NH)
  • Villas / meter cabinets per way
  • Owner: authority / consumer
 Treated as a board: loading, diversity across villas, fuse discrimination with the villa incomer, voltage drop to the furthest villa
VCBMV switchboard / VCB panel — consumer HV board for large plots (several RMUs or HV motors)
  • Panels: incomer, bus coupler, outgoing feeders
  • Rated voltage kV, busbar A, Ik kA 3 s
  • Breaker: VCB withdrawable, rating A
  • Relay: 50/51, 50N/51N, 87T (optional) and settings
  • Interlocks (incomers / coupler)
 MV fault level, relay grading against the transformer and LV ACB (future)
MVCMV cable — between the source, RMU / VCB and transformer
  • Type: 1C / 3C, Cu / Al, XLPE, 6.35/11 kV or 12/20 kV
  • Size mm², runs, length m
  • Screen: Cu tape / wire, screen fault rating kA 1 s
  • Installation: buried / duct / tray
 MV voltage drop, impedance added to the source, screen and conductor short-circuit check (adiabatic)
HVMHV metering unit — CT / VT metering where the authority meters on the HV side
  • CT ratio, class (0.2S / 0.5S)
  • VT ratio, class
  • Meter type, owner
 Labels only (no calculation)

D. Typical arrangements

1. Large project — own substation

Primary substation → 11 kV cable → RMU (RRT) → transformer → LV MDB (as today). 11 kV · 500 MVA · X/R 10

2. Villa community

Authority package substation → LV feeder pillar → villa meter cabinets. PSS 1000 kVA · FPL 4 × 250 A

3. Single villa, existing substation

Existing authority substation LV way → meter cabinet → villa MDB. 1000 kVA · 120 m 4C × 240 mm² · 200 A

4. Mains + mobile generator

Mains, with a mobile generator hook-up through an MGCP and a manual transfer switch. MG 250 kVA · MGCP 400 A

5. Off-grid / hybrid site

Two DG sets in sync, PV and battery on the common bus, feeding the MDB. 2 × 500 kVA · PV 300 kWp · BESS 500 kWh
