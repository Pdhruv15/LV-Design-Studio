5Snaps and changed-source safety

Vector PDFcalibratedVector snaps on Only verified stroked path endpoints, midpoints and intersections; transforms and clipping applied.
Scanned PDF / imagepixelsNo snaps No OCR, edge detection or guessed linework. Two calibration points can still be picked freely.
Source changedmanual reloadVerify calibration The old display stays until Reload. Snaps stay off until calibration is confirmed or redone.
If the file moves, Repath… opens a file dialog. Page, placement, clip and calibration settings remain; the app never searches arbitrary folders or edits the source.

6Plan-sheet behavior remains black-and-white

Print is off by default. If enabled, the underlay is grayscale regardless of its screen setting. Save DXF/DWG omits it in the first build and reports that omission.

7Approval choices

  1. Reverse the earlier decision and build underlays now: yes recommended.
  2. Use the existing References manager: yes recommended.
  3. Allow an empty 2D host for PDF/image-only levels: yes recommended.
  4. Allow uncalibrated placement, clearly marked, with snaps off: yes recommended.
  5. Snaps from verified vector PDF paths only, fail closed: recommended.
  6. Monochrome on, fade 60 %, print off; print always grayscale: recommended.
  7. Include single-page TIFF with PNG/JPEG/WebP/BMP: recommended.
  8. Changed sources reload manually and require calibration verification: recommended.
