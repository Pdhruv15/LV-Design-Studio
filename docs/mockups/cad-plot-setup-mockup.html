Design CAD → Sheets → Plot — page setup, pen table and publish mockup (2026-11-06)

Each sheet gets a page setup (paper, orientation, scale, what is plotted), and the set has a pen table that decides how thick every kind of line prints — the app's own (devices, trays, cables, text, frame) and the architect's background, either one thin grey, the lineweights stored in the DWG, or a CTB file from your CAD folder. Publish then prints one sheet, the ones ticked, or all, as one PDF or one file per sheet. Printing stays black-and-white.

      Notes for the decision
      • Where: a new Plot group on the Sheets sub-tab (Page setup, Pens, Preview), beside Issue and export. The Publish dialog keeps today's readiness checks and Issue, and gains the sheet list, the output kind and file names.
      • Page setup is kept per sheet (blank = the set's default). Auto paper keeps today's behaviour (the smallest of A3–A1 that fits). Scale applies to plan sheets; SLD sheets stay "fit" as now.
      • Pen table: one per project, chosen per sheet. Widths from the ISO series 0.13 / 0.18 / 0.25 / 0.35 / 0.5 / 0.7 / 1.0 / 1.4 / 2.0 mm, black or a grey. The defaults match what the sheets print today, so nothing changes until you edit it.
      • CTB from your CAD files: a .ctb sits in the AutoCAD Plot Styles folder, not in the DWG. Import reads its 255 colours → lineweight and screening (grey); the architect's lines then print by their colour. Or use the lineweights stored on the DWG's layers. STB (named styles) later.
      • Preview shows the sheet as it will print, at the pen widths (zoom to check). The same widths go into the PDF; DXF/DWG get the lineweights on their layers.
