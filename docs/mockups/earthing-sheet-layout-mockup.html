Earthing schematic sheet — layout mockup

Proposal, 2026-11-10 · Reports → Drawings and Design CAD → Sheets · Earthing schematic (E-EAR-001) · black-and-white output, as today

The problem. The schematic draws one band per substation / main board, stacked top to bottom, with the legend, notes and pit schedule underneath. On the demonstration project that makes 9 bands plus the schedule: a drawing about three times taller than it is wide. Scaled to fit the height of a landscape sheet, it uses only about 25–30% of the drawing area and every label prints very small.

Today — one tall column, fit to the sheet height

9 bands + legend + 70-row pit schedule in one column. Width used ≈ 28%. Text prints at about 1 mm on A1 and is unreadable on A3.

Option A (recommended) — bands flow into columns, the pit schedule takes its own column

The bands are kept whole and flow down the first column, then the next, like newspaper columns. The app tries 1, 2, 3 … columns and keeps the count that gives the largest scale. The legend and notes move into the sheet's legend column (the same column the SLD sheets already use). The pit schedule sits in its own column on the right of the drawing area. Nothing inside a band changes: same symbols, conductors, pit tags and cable sizes.

Same content, 2 band columns + schedule column. Width used ≈ 95%. Drawing scale about 2.5× today's, so text prints about 2.5 mm on A1 and stays readable on A3.

Option B — Option A, with continuation sheets when the scale gets too small

If even the best column count would print text smaller than a set minimum (proposed 2.0 mm on the chosen sheet size), the bands split across continuation sheets — whole bands only, never a band cut in half — with the pit schedule on the last sheet. The title block numbers them E-EAR-001 sheet 1 of 2, 2 of 2, the same way the riser continuation sheets work today. A small project with one or two substations stays on one sheet.

Demonstration project on A3: two sheets, text about 2–3 mm. On A1 the same project fits one sheet (Option A).

What changes and what does not

ChangesStays the same
  • Band arrangement: columns chosen for the largest scale
  • Legend and notes in the sheet's legend column
  • Pit schedule in its own column (or on the last sheet)
  • Option B only: continuation sheets below a minimum text size
  • Everything inside a band: symbols, earth bars, test links, pit tags, cable sizes
  • Black-and-white output, frame and title block
  • PDF, DXF and Design CAD → Sheets all use the same layout
  • Sheet size choice (auto or fixed) in the drawing set

Separately — printing through the Windows print dialog

The sample PDF was made with Print → Adobe PDF onto US Letter. That shrinks the sheet further, turns the text into drawn shapes (slow to open, not searchable) and adds tiny images. That is not a layout issue: the app's own Export PDF keeps the sheet size and real text. No change proposed here.

Decisions needed

  • Option A only, or Option A + B (continuation sheets)?
  • If B: minimum printed text height — 2.0 mm proposed (2.5 mm is the usual drawing minimum on A1).
  • Pit schedule: own column on the earthing sheet (proposed), or always a separate schedule sheet?
