Detached windows for Design CAD and the SLD

Proposal, 2026-11-26. A tab moves out of the main window into a window of its own, for example the plan on a second monitor beside the SLD.

new item

1 · Today

One window. The SLD and the plan cannot be seen at the same time. The tab menu can only close drawings.

2 · Move to new window

Design CAD tab row
SLD tab row
The SLD tabs have no right-click menu today.
Right-click a tab, or use the button at the end of the tab row.

3 · Two monitors

Monitor 1 · main window
Monitor 2 · Design CAD window
One project in both windows. Show on plan on the SLD brings the Design CAD window forward and zooms to DB-G1. Undo, Save and keys work in either window.

4 · Main window while Design CAD is out

Shown only if the page is opened in the main window anyway, for example from the Stages tab.

5 · An SLD tab in its own window

Pick a board in the System diagram window: the Board tab in the main window shows that board.

What stays

  • Pages, tools, colours and wording inside each page do not change.
  • Plots, PDFs and exports do not change and stay black-and-white.
  • Saved projects and drawings do not change.
  • With no tab detached, the app works exactly as today.

Decisions

A. Design CAD window: the whole page (one drawing per window later, step 4)
B. SLD window: one SLD tab, selection shared
C. Detach: right-click + button; drag a tab out later (step 5)
D. Close a detached window: puts the tab back, no question
E. Ribbon there: Design CAD sub-tabs only
F. Reopen: remember place and size; every tab starts in the main window
