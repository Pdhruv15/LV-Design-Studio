Project folder customisation: mockups C1–C8

For the proposal "UI UX proposals - 2026-11-09 - Project folders customisation". These are static mockups in the app's Graphite colours, built with the app's chip, tab, modal and table styles. The template data comes from folder-templates.json in this folder. The sample project is 2417 "Al Barsha Villas", with buildings B1 and B2.

You can select tree rows, edit the folder name in C2 (try typing &), use the Roles filter, add and remove naming tokens, and switch the wizard steps. Nothing touches the disk.
